# RPG AdminQuest

Telegram-бот с системой RPG-квестов для геймификации рабочего процесса команды разработки.

## 🎮 Функционал

- **RPG-система** — уровни, титулы (AnyKeyMan → Junior → Middle → Senior), EXP, прогрессия до 400 уровней
- **Квесты** — создание, взятие, сдача, передача задач с таймаутами и наградами
- **Инциденты** — автоматическое создание критических задач по ключевому слову
- **Wiki-база знаний** — сохранение решений, AI-категоризация, векторный поиск по эмбеддингам
- **AI-анализ** — автоматическое определение приоритета, компании, контакта, VIP-статуса
- **Планировщик** — фоновые задачи: таймауты, деградация скиллов, еженедельные отчёты
- **Телефония** — интеграция с CallHandler (входящие вызовы → квесты)
- **Веб-форма** — публичная форма заявок на квесты (Flask, защита от спама)
- **Прокси-менеджер** — ротация прокси для Telegram API
- **Telegram Tags** — автоматическая установка тегов уровня в чате

## 📋 Требования

- Python 3.10+
- pip
- SQLite (входит в стандартную библиотеку)

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/NeoEraser/RPG-AdminQuest.git
cd RPG-AdminQuest
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` с переменными окружения:
```env
BOT_TOKEN=your_telegram_bot_token
TEAMLEAD_ID=123456789
DB_NAME=gamebot_rpg.db
PROXY_URL=http://user:pass@proxy:port
GROUP_ID=-1001234567890
message_thread_id=0

# AI-анализ (опционально)
AI_BASE_URL=https://api.example.com/v1
AI_MODEL=gpt-4
AI_TEMPERATURE=0.7
AI_MAX_TOKENS=1000
AI_ENABLED=true
```

5. Запустите бота:
```bash
python main.py
```

## 🎯 Команды бота

### Основные (для всех)
| Команда | Описание |
|---------|----------|
| `/start` | Начать игру, принять условия использования |
| `/profile` | Ваш уровень, опыт, прогресс |
| `/top` | Доска почёта: топ месяца и легенды |
| `/quests` | Список активных квестов |
| `/quests_list` | Полный список квестов с фильтрами |
| `/help` | Справка по всем командам |
| `/wiki` | Открыть базу знаний |
| `/wiki_add` | Добавить статью в Wiki (тимлид) |
| `/wiki_review` | Проверить новые статьи (тимлид) |

### Квесты
| Действие | Описание |
|----------|----------|
| Написать "НовыйКвест ..." | Создать новый квест |
| Написать "инцидент ..." | Создать критический инцидент |
| Кнопка "⚔️ Взять квест" | Принять квест в работу |
| Ответ "Готово: ..." | Сдать квест с отчётом |
| Ответ "Передать @ник" | Передать квест другому |
| Кнопка "💡 Подсказка AI" | Получить AI-подсказку |
| `/cancel` | Отменить текущее действие |

### Администратор (тимлид)
| Команда | Описание |
|---------|----------|
| `/dashboard` | Live Status — кто чем занят |
| `/smite ID EXP причина` | Штраф игрока |
| `/vacation ID с по` | Отпуск игрока |
| `/reindex_now` | Переиндексация Wiki |

## 🎮 Игровая механика

### Титулы и уровни

| Титул | EXP | Уровней |
|-------|-----|---------|
| AnyKeyMan | 0 – 200 | 1–100 |
| Junior | 200 – 1 000 | 101–200 |
| Middle | 1 000 – 5 000 | 201–300 |
| Senior | 5 000 – 25 000 | 301–400 |

### Награды

| Тип квеста | EXP | Время |
|------------|-----|-------|
| Обычный квест (детальный отчёт) | +5 | 4 часа |
| Обычный квест (сухой отчёт) | +1 | 4 часа |
| Критический инцидент | +15 | 1 час |
| Сохранение в Wiki | +5 | — |

### Штрафы

| Причина | EXP |
|---------|-----|
| Пропуск таймаута квеста | − |
| Отклонённая задача | −5 |
| Пропуск "плана на завтра" | −1 |
| Команда `/smite` | настраивается |

## ⏰ Фоновые задачи

| Задача | Расписание | Описание |
|--------|-----------|----------|
| `daily_plan_check` | Пн-Чт, 18:00 | Проверка "план на завтра" |
| `skill_decay_check` | Вт-Пт, 10:00 | Деградация EXP за неактивность |
| `reset_monthly_exp` | 1-е число, 00:00 | Сброс monthly EXP |
| `monthly_results_check` | Последнее число, 12:00 | Итоги месяца |
| `generate_weekly_report` | Пн, 09:30 | Отчёт "Глаз директора" |
| `wiki_reindex` | Ежедневно, 01:00 | Переиндексация Wiki |

## 🔌 Интеграции

- **Telegram Bot API** — основной интерфейс
- **AI API** — анализ задач (настраиваемый base_url/model)
- **Телефония** — CallHandler (порт 5000), входящие → квесты
- **Веб-форма** — Flask (порт 5001), публичная форма заявок
- **Прокси-менеджер** — ротация прокси для Telegram API
- **Telegram Tags API** — автоматическая установка тегов уровня

## 🗄️ База данных

SQLite-база (`gamebot_rpg.db`) содержит таблицы:

- `users` — игроки (exp, monthly_exp, agreed_to_tos)
- `tasks` — квесты (open / in_progress / completed / canceled)
- `task_metadata` — приоритет, компания, VIP, контакт
- `task_timeouts` — активные таймауты
- `quest_messages` — история переписки по квестам
- `quest_wiki_usage` — использование Wiki при сдаче
- `exp_history` — история изменений EXP
- `vacations` — отпуска
- `proxies` — пул прокси с рейтингами
- `wiki` — база знаний
- `companies` — компании для AI-анализа
